# File Naming Convention for Game Hub

## Preferred Convention: kebab-case

All new files should use **kebab-case** (lowercase, hyphen-separated) for consistency and web-friendliness.

### Examples of Kebab-case:
- `tower-defence.html`
- `tic-tac-toe.html`
- `snake-game.html`
- `mini-golf.html`
